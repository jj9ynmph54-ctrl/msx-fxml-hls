# MSX FXML HLS Test

Small static GitHub Pages project for testing a direct HLS (.m3u8) URL with Media Station X/FXML.

Use only direct streams you are authorized to access. This project does not bypass DRM, authentication, paywalls, or access controls.

## Setup
1. Upload the files to a GitHub repository.
2. Enable GitHub Pages for the repository.
3. Open the published `index.html`.
4. Enter a direct `.m3u8` URL and a title.
5. The page generates a simple FXML item for testing.
